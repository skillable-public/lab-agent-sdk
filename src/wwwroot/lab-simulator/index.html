AI Chat Mentor — Integration Sandbox

Welcome. This sandbox includes a lab simulator that embeds an AI Chat Mentor iframe in a simulated Skillable lab, and a sample chat agent you can load as a reference implementation. Pick a flow below to begin.

Test a Mentor Agent

Embed your own mentor iframe in the simulated lab to drive it through the full postMessage handshake and contract.

Must be served over HTTPS in production. Localhost / dev URLs are fine while you're building.

View a Sample Integration

Open the simulated lab with a pre-built reference mentor embedded in it — the same one whose source ships in this repository. Useful as a working example of the integration end-to-end.

  • Exercises every mentor.* message in the contract.
  • Uses scripted (non-LLM) replies so the behavior is predictable.
  • No external dependencies beyond what this repo provides.

Launch-token verification

The chat agent backend will accept launch tokens from these issuers. To integration-test against a real Skillable lab client, add an entry to LaunchToken:ChatAgent:TrustedIssuers in appsettings.json and restart.
